# RaceGenderChanger

Change your own character's race and gender to Lalafell (or other races!)

- Created by: Avaflow
- Smol update by Ars Magna for to run in 6.2
- Updated to 7.2 by Kelvin
- Updated by Blaksey to update only your character and allow for Gender changes

## Usage
Build the plugin, add as dev extension. Not currently publishing this publicly.
Install and enable Penumbra and RaceGenderChanger.

## ⚠️ READ THIS ⚠️

- **Requirement**: This plugin requires [Penumbra](https://github.com/xivdev/Penumbra) (another Dalamud plugin) to be installed and active.
- **Note**: This plugin now only affects your own character, not other players.
